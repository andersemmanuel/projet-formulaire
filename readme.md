# Projet Formulaire PHP

Un projet de formulaire web développé en PHP avec une interface utilisateur moderne et responsive.

## Structure du Projet

```
.
├── asset/         # Ressources statiques (images, etc.)
├── controller/    # Contrôleurs PHP
├── css/          # Feuilles de style
└── index.php     # Point d'entrée de l'application
```

## Technologies Utilisées

- PHP
- HTML/CSS
- JavaScript

## Installation

1. Clonez ce dépôt
2. Assurez-vous d'avoir PHP installé sur votre machine
3. Configurez votre serveur web (Apache/XAMPP) pour pointer vers le répertoire du projet

## Fonctionnalités

- Formulaire de connexion
- Interface utilisateur responsive
- Design moderne et épuré
